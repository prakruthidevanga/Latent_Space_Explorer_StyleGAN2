# Latent Space Explorer — StyleGAN2

A local Streamlit application for exploring how interpolating between two latent vectors changes an image generated by a **real pretrained StyleGAN2-ADA PyTorch generator**.

## What it demonstrates

- Two deterministic seed inputs (Seed A and Seed B).
- Linear latent-vector interpolation using `z(t) = (1 - t) * z_A + t * z_B`.
- Generated start, current-interpolation, and end images.
- A gallery of intermediate images generated by the same pretrained network.
- Numerical diagnostics: endpoint L2 distance and distances from the current vector to both endpoints.
- A chart showing selected coordinates of the latent vectors.
- Unit tests for interpolation mathematics and deterministic seeds.

**Important:** this ZIP contains source code, not the large pretrained checkpoint or NVIDIA's third-party source tree. Download those before expecting real images. If the model is unavailable, the UI tells you what is missing; it does not disguise placeholder images as generated results.

## Model choice

The default checkpoint is **AFHQ Cat (512 × 512)** from the official NVIDIA StyleGAN2-ADA PyTorch pretrained model collection. This is smaller/faster for a classroom demonstration than the 1024 × 1024 FFHQ checkpoint, while still producing useful images for latent interpolation.

Official implementation and model documentation:
- https://github.com/NVlabs/stylegan2-ada-pytorch
- Default pretrained checkpoint: https://nvlabs-fi-cdn.nvidia.com/stylegan2-ada-pytorch/pretrained/afhqcat.pkl

Review the official repository/model terms before use or redistribution. Checkpoint files are Python pickle files: load only a trusted checkpoint.

## Requirements

- Windows 10/11
- Python 3.10 or 3.11 recommended for compatibility with the older StyleGAN2-ADA code
- Git
- Internet access for installing packages, cloning the official repository, and downloading the checkpoint
- CPU can be selected; CUDA-capable NVIDIA hardware is recommended for faster generation

StyleGAN2-ADA may require compatible versions of PyTorch and its custom operations. If a particular Python/PyTorch combination fails, use a supported Python version and follow the official repository's setup guidance.

## Windows setup (PowerShell)

1. Extract the ZIP to a writable folder.
2. Open PowerShell in the extracted `Latent_Space_Explorer_StyleGAN2` folder.
3. Run the setup script:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup_windows.ps1
```

The script creates `.venv`, installs the listed dependencies, and clones NVIDIA's official StyleGAN2-ADA PyTorch source into `third_party`.

4. Download the pretrained checkpoint (this is a large file):

```powershell
.\.venv\Scripts\python.exe download_model.py --model afhqcat
```

This should create `models\afhqcat.pkl`. Other supported checkpoint names include `afhqdog`, `afhqwild`, `ffhq`, and `metfaces`; if choosing a different model, adjust the checkpoint path in the sidebar.

5. Start the application:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

The browser should open the local Streamlit page. If it does not, open the local URL printed in the terminal, usually `http://localhost:8501`.

Alternative: once setup is complete, double-click `run_app.bat`.

### PyTorch / CUDA note

`requirements.txt` installs a PyTorch version range chosen to reduce compatibility risk with the older StyleGAN2-ADA code. For GPU acceleration, use the official selector at https://pytorch.org/get-started/locally/ to install the build compatible with your Windows/Python/CUDA setup. In the app, select **Auto** or **CUDA**. CPU inference works where the checkpoint and dependencies support it, but 512-pixel generation can be slow.

## Run tests

Run the pure-math tests (no checkpoint required):

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests\test_latent_utils.py
```

The real checkpoint integration test is skipped by default. After downloading the model and cloning the source repository, run:

```powershell
$env:LATENT_EXPLORER_RUN_MODEL_TEST="1"
.\.venv\Scripts\python.exe -m pytest -q tests\test_model_integration.py
```

Do not call the integration test successful unless it was actually executed and passed.

## How the application works

1. A seed initializes a private PyTorch random-number generator, producing a reproducible standard-normal Z vector with the dimension required by the loaded generator.
2. The interpolation function calculates an intermediate Z vector using `z(t) = (1 - t) * z_A + t * z_B`.
3. The StyleGAN2 generator uses its learned mapping network to map Z into its internal style representation, then its synthesis network generates an image.
4. The output tensor is converted from NCHW values in approximately `[-1, 1]` into an RGB image for display.
5. The app shows the endpoint images, the selected interpolated image, the full sequence, and numerical diagnostics.

The project interpolates in **Z space**. Some StyleGAN workflows interpolate in W or W+ instead; these are different latent representations. The implementation must stay consistent with its selected space and uses the model's standard `G(z, c=None)` generation path.

The L2 distance metric is a numerical distance between latent vectors. It is **not** a perceptual image-similarity score. Interpolation also does not guarantee that every intermediate image will look like a perfect semantic blend.

## Troubleshooting

- **Checkpoint not found:** run `python download_model.py --model afhqcat` and verify `models/afhqcat.pkl` exists.
- **StyleGAN source missing:** run the `git clone` command from the setup script or clone NVIDIA's official repository to `third_party/stylegan2-ada-pytorch`.
- **CUDA unavailable:** select Auto or CPU; generation may take longer.
- **CUDA selected but not detected:** install a compatible PyTorch/CUDA build or select Auto/CPU.
- **Custom-op or dependency build errors:** follow the official StyleGAN2-ADA repository's compatibility instructions; older model code can be sensitive to Python/PyTorch/compiler versions.
- **Out of memory:** select CPU, close GPU-heavy applications, or use a lower-resolution compatible checkpoint. Do not resize a checkpoint's architecture by changing only the UI.
- **Checkpoint loading error:** verify the file completed downloading and came from the official model host. Do not load unknown pickle files.

## Viva quick notes

- **Latent vector:** a numeric code supplied to the generator.
- **Seed:** initializes random generation reproducibly.
- **Interpolation:** calculates points between two latent vectors.
- **Generator:** maps the latent representation to an image.
- **Pretrained weights:** learned parameters used for image generation without training from scratch.
- **Mapping network:** converts Z-space input into the style representation used inside StyleGAN2.
- **Synthesis network:** converts learned style information into image pixels.
- **Endpoint test:** at `t=0` the result must equal Seed A's latent vector; at `t=1` it must equal Seed B's latent vector.
- **Visible diagnostic:** L2 distance measures numeric vector difference, not image perceptual similarity.
